# Python in 20 Days (plus an advanced path)

One folder per day. Everything for that day is in one place:

```
week1_basics/day01_hello_python/
├── lesson.md     read first: the idea, why it exists, an analogy, every code block explained
├── example.py    run it, change it, break it on purpose
├── more_examples.py   10 more examples, simple to complex, each explained
└── practice.py   your turn: fill it in
```

## How to study each day (about 1.5 to 2.5 hours)

1. **Read** `lesson.md` (20 min). Do not skip "Simple way to understand".
2. **Run** `example.py`: `python3 week1_basics/day01_hello_python/example.py`
3. **Change** it and read any error message you cause.
4. **Practise**: fill in `practice.py` and do the tasks at the end of the lesson.
5. **Self-check**: answer the questions without looking.

If you only read, you will forget. If you type and break things, you will remember.

## How the days build on each other

```
1-7    output, variables, text, input, operators, decisions   ──► first project
8-14   loops, lists, tuples/sets, dicts, functions            ──► repeat and organise data
15-20  files, errors, modules, classes, JSON                  ──► real programs, final project
21-24  comprehensions, lambda, decorators, generators         ──► cleaner, faster Python
25-28  venv, APIs, CSV/JSON, command-line tools               ──► skills every track needs
tracks data, web, automation, AI/ML, cloud                    ──► specialise
```

Three ideas run through everything: **data** (variables, lists, dicts), **flow** (if, for, while) and **packaging** (functions, modules, classes).

## Setup

```bash
python3 --version                      # 3.9 or newer
cd python-20-days
python3 week1_basics/day01_hello_python/example.py
```

For Day 25 onward and all tracks, use a virtual environment (Day 25 explains why) and install only what you need:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install requests                                        # Days 26 and 28
pip install numpy pandas matplotlib                         # Track 1
pip install flask fastapi "uvicorn[standard]" httpx django  # Track 2
pip install beautifulsoup4 selenium                         # Track 3 (Selenium also needs Chrome)
pip install scikit-learn torch                              # Track 4 (torch is large)
pip install boto3 "moto[s3,ec2,sts]" oci                    # Track 5: AWS (+ fake AWS), OCI
pip install azure-identity azure-mgmt-resource azure-mgmt-resource-subscriptions azure-mgmt-compute   # Track 5: Azure
```

Useful commands: `make run` (run a sample), `make check` (compile every file), `make clean`.

## Safety notes

- Cloud examples contain no credentials. They read them from the environment or standard config files. Never put keys in code or commit them.
- Web scraping: read a site's terms and `robots.txt` first, and keep request rates low.
- Examples that use the network or a cloud account say so at the top of the file.
